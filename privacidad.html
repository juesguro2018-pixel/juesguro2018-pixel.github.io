Política de privacidad

Última actualización: 20 de noviembre de 2026

Nova es un asistente personal de uso privado. Su único usuario es su propietario y creador.

Datos de Google a los que accede

  • Gmail: leer correos para resumirlos y detectar estafas; mover correos sospechosos a una etiqueta; crear borradores; enviar o mover a la papelera solo cuando el propietario lo confirma.
  • Google Calendar: leer eventos y crear, cambiar o borrar eventos solo con confirmación del propietario.

Cómo se usan

Los datos se usan únicamente para dar estas funciones al propietario. No se venden, no se comparten con terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial generales.

Para entender las peticiones, el texto necesario se procesa con un servicio de inteligencia artificial (Anthropic Claude) bajo sus condiciones de uso por API. La información se guarda en una base de datos privada a la que solo accede el propietario.

El uso de la información recibida de las API de Google cumple la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo retirar el acceso

El acceso se puede quitar en cualquier momento desde myaccount.google.com/permissions.
